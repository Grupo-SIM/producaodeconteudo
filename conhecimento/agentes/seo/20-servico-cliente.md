# Cliente de serviço: SEO

Vale só para marcas de clientes de serviço. Nada das nossas marcas entra aqui, e nenhum link para os nossos blogs.

1. A palavra-chave é o que o público do cliente digita no Google. Para negócio local, inclua cidade ou bairro quando fizer sentido (ex.: "pizzaria no centro de Rio Branco").
2. Título SEO de até 60 caracteres, meta description de até 155 e URL curta com a palavra-chave.
3. Perguntas reais do público respondidas como subtítulos, sem seção de perguntas frequentes no fim.
4. Links internos só para outros conteúdos do próprio cliente, e para o canal do objetivo do briefing (pedido, reserva, agenda, mapa).
5. Endereço, horário e telefone sempre iguais aos do briefing, porque o Google confere a consistência dessas informações.
6. Nunca mude o tom nem a história para encaixar palavra-chave.
